# 登录页面与普通用户登录开关

管理员登录页使用新的自适应布局，支持邮箱标签、浏览器自动填充、显示／隐藏密码、表单校验和登录中的按钮状态。管理员入口地址保持原来的 `secure_path`，完整及受限管理员均可登录。

在「设置 → 系统配置 → 站点」中配置「普通用户登录」。新配置项为 `user_login_enable`，默认值为 `0`，即暂停普通用户登录；开启后值为 `1`，恢复原来的用户中心主题。

关闭时：

- 首页显示用户中心暂停提示，不加载普通用户的登录、注册等页面，也不显示后台入口地址。
- 普通用户的密码登录、注册自动登录、快捷登录凭证兑换和快捷登录链接生成均被后端拦截。
- 完整和受限管理员仍可从原后台地址登录。`is_staff` 本身不绕过暂停开关。
- 已有用户会话不会被主动退出，订阅接口和节点接口继续使用原有流程。

管理员登录表单发送 `admin_login=1`，普通用户无法通过此表单创建会话，即使普通用户登录开关已开启。该参数不会赋予任何管理员身份。

开关沿用现有系统配置保存到 `config/v2board.php`，不需要新增 SQL。拥有系统配置修改权限的管理员可以操作；仅查看配置的账号不能切换。

## 更新

拉取代码后清理配置、路由和视图缓存，再重建配置缓存。登录页面静态资源已更新缓存版本。

```sh
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan config:cache
```

使用常驻 Web 进程时，按原部署方式重启对应进程，以加载最新代码。仅为本次页面及登录开关更新，不需要重启 Horizon 队列。

## 验证

```sh
vendor/bin/phpunit
node --check public/assets/admin/umi.js
```

登录开关测试使用 SQLite 内存数据库；配置保存测试通过模拟文件写入验证，不修改实际站点配置。
